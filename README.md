# Qyra

AI hosts from around the world who come online on their own local time.
Every host is an AI character, aged 18+.

## Files
- `index.html`, `favicon.svg`, `manifest.webmanifest`, `icons/` : the app. Updated with `qyra-app.zip`.
- `hosts.json` and `photos/` : the hosts. Updated only by the Export button in Qyra Admin (`qyra-hosts.zip`).

App updates never include `hosts.json` or `photos/`, so your hosts and photos are never overwritten.
Never put `qyra-admin-backup.zip` in this repo: it contains the private image prompts.
